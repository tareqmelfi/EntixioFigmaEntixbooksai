# ENSIDEX WAVE IMPORT · ملف الاستيراد الرئيسي
> عبّئ هذه الملفات الأربعة (أو صدّر ما يقابلها من برنامجك الحالي) وأرسلها لي — كلها تدخل النظام من بوابة واحدة.

## أين تُستورد؟ (الإجابة الرسمية)
**بوابة واحدة**: داخل التطبيق ← لوحة التحكم ← «أكمل إعداد شركتك» ← معالج النقل 4 خطوات:
1. **opening-balances.csv** → قيد افتتاحي واحد متوازن (رأس المال المدفوع يُحسب تلقائيًا)
2. **products.csv** → الأصناف + رصيد مخزون افتتاحي اختياري
3. **contacts.csv** → عملاء وموردون (dedupe بالاسم)
4. **bank-statement.csv** → الحسابات البنكية ← استيراد كشف (مطابقة تلقائية)

ملف غير منظم أو صورة/PDF؟ زر «استخراج AI من ملف» بنفس المعالج يحوّله صفوفًا.

## من Wave تحديدًا (waveapps.com)
| ماذا | وين تجيبه في Wave | أي ملف يقابله |
|---|---|---|
| العملاء | Sales → Customers → Export CSV | contacts.csv (type=customer) |
| الموردون | Purchases → Vendors → Export CSV | contacts.csv (type=supplier) |
| الأصناف | Sales → Products & Services → Export | products.csv |
| كشف البنك | Accounting → Transactions → Export (أو كشف البنك نفسه) | bank-statement.csv |
| الأرصدة الافتتاحية | من ميزان المراجعة Trial Balance | opening-balances.csv |

## من وافق (Wafeq) أو أي نظام آخر
نفس الملفات — الأعمدة الإنجليزية الشائعة مدعومة بالاسمين (name/customer_name/الاسم …).
