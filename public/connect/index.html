الربط من ChatGPT Connect your books inside ChatGPT

يعمل هذا الربط داخل ChatGPT؛ لا يحوّل اشتراكك إلى رصيد لمساعد Entix. تحتاج صلاحية مالك أو مدير للشركة في Entix، وإتاحة التطبيقات المخصصة في حساب ChatGPT أو مساحة عملك.

This connector runs inside ChatGPT; it does not fund the assistant inside Entix. You need an Entix company owner/admin account and custom-app access in ChatGPT.

عنوان الربط · MCP server URL: https://api.entix.io/mcp · نسخ العنوان

  1. افتح إعدادات ChatGPT ← التطبيقات ← الإعدادات المتقدمة، وفعّل وضع المطوّر إن كان متاحًا. قد يلزم مدير مساحة العمل لمنح هذه الصلاحية.Settings → Apps → Advanced settings → Developer mode. Workspace access may require an admin.
  2. أنشئ تطبيقًا باسم Entix Books، واستخدم العنوان أعلاه واختر OAuth، ثم افحص الأدوات وأكمل المصادقة.Create an app named Entix Books with the URL above, choose OAuth, then Scan Tools and complete authorization.
  3. سجّل الدخول إلى Entix، واختر الشركة والصلاحيات. ابدأ بالقراءة فقط وأكمل إنشاء التطبيق في ChatGPT.Sign in to Entix, choose the company and read-only permissions, then finish creating the app in ChatGPT.
  4. افتح محادثة واختر التطبيق. اطلب اسم الشركة وعملتها وتحقق من النتيجة قبل منح أي صلاحيات إضافية.Select the app in a chat and ask it to use get_company. Verify the company and currency before granting more permissions.

إذا لم يتوفر إنشاء التطبيق، راجع خطة ChatGPT وصلاحيات مساحة العمل. عند انتهاء الوصول أعد الربط؛ لا يصدر موصّل Entix رمز تجديد تلقائي حاليًا.

If app creation is unavailable, check your ChatGPT plan and workspace permissions. Reconnect when access expires; Entix does not currently issue refresh tokens.

للمطورين: Claude Code وواجهة MCP

Claude Code وأي عميل MCP آخر Streamable HTTP · OAuth 2.1 or API key

استخدم عميلًا يدعم MCP عبر Streamable HTTP والمصادقة المناسبة. في Claude Code، أضف الخادم بالأمر التالي ثم افتح /mcp لإكمال المصادقة. ويمكن للعملاء الذين يدعمون ترويسة Authorization استخدام مفتاح API (الإعدادات ← مفاتيح API) كـ Bearer.

claude mcp add --transport http entix-books https://api.entix.io/mcp
# or with an API key from Settings → API keys
claude mcp add --transport http entix-books https://api.entix.io/mcp \
  --header "Authorization: Bearer ek_live_…"

Discovery: /.well-known/oauth-protected-resource · /.well-known/oauth-authorization-server · PKCE S256 · dynamic client registration · stateless JSON-RPC (POST /mcp).

الأمان — ما الذي يحدث فعلاً عند الربط Security model

شركة واحدة لكل ربطالموافقة تُنشئ مفتاح API مقيّدًا بالشركة التي اخترتها. لا يستطيع الوكيل رؤية أي شركة أخرى، حتى لو كنت عضوًا فيها.
صلاحيات بالحد الأدنىالأدوات التي لم تمنحها لا تظهر أصلاً للوكيل. القراءة فقط تحجب أدوات الكتابة وترفض استدعاءها. صلاحية كتابة واحدة تتيح أيضًا أدوات القراءة للشركة.
مالك أو مدير فقطصفحة الموافقة لا تقبل إلا عضوية OWNER أو ADMIN — نفس قاعدة إنشاء مفتاح API من الإعدادات.
إلغاء بضغطةالإعدادات ← مفاتيح API ← إلغاء. المفتاح ينتهي تلقائيًا بعد 365 يومًا، ويُخزَّن مجزّأً (sha256) ولا يُعرض مرة أخرى.
تتبع العمليات وإعادة المحاولةمسارات الكتابة تسجّل source=api_key ورقم المفتاح في سجل التدقيق. إعادة المحاولة تحتاج نفس externalId في الاستيراد؛ لا يكفي الاعتماد على نص الطلب. استخدم dryRun حيث تدعمه الأداة وراجع نتيجة كل صف قبل الحفظ.
مصادقة OAuth مع PKCEرمز الموافقة صالح لمدة 5 دقائق ومربوط بطلب الاتصال. يحتفظ عميل MCP برمز الوصول؛ يخزن Entix بصمته للتحقق منه. أدوات البيانات تمر عبر /api/v1 نفسه.

أسئلة شائعة FAQ

هل أستخدم اشتراكي لتشغيل مساعد Entix داخل المنصة؟

الموصّل أعلاه يتيح العمل من داخل ChatGPT أو Claude. استخدام اشتراك ChatGPT داخل Entix غير مفعّل حاليًا؛ يتطلب قبول Entix ضمن برنامج OpenAI للتطبيقات التجارية ثم تهيئة واختبار الربط. اشتراك Claude الشخصي ليس وسيلة مدعومة لتشغيل مساعد Entix؛ لا نجمع بيانات دخوله أو رموز جلسته. إعدادات BYOK ورصيد المنصة تبقى مستقلة.

The connector runs in ChatGPT or Claude. ChatGPT plan usage inside Entix is not enabled; it requires commercial-program acceptance and integration testing. Personal Claude subscriptions cannot power the Entix assistant. Entix does not collect Claude login or session tokens. BYOK and platform credit remain separate.

هل أحتاج مبرمجًا؟

لا يلزم كود للربط من claude.ai. أضف العنوان، ثم أكمل تسجيل الدخول والموافقة. المطوّرون يجدون الواجهة البرمجية الكاملة في التوثيق.

هل يستطيع Claude حذف بيانات أو إغلاق فترة؟

لا. لا توجد أدوات حذف أو إقفال فترات أو تغيير إعدادات عبر الموصّل. حتى reconcile_bank_transaction تعمل داخل قفل دفتر الأستاذ نفسه الذي يستخدمه التطبيق.

عندي عدة شركات؟

اربط كل شركة كموصّل مستقل (اسم مختلف لكل ربط). كل موصّل يرى شركته فقط.

العملات الأجنبية؟

الوكيل لا يفترض سعر صرف أبدًا؛ عند تصنيف بند من حساب بعملة غير عملة الشركة يجب تمرير baseAmount صراحة — نفس قاعدة التطبيق.

كيف أوقف الربط فورًا؟

الإعدادات ← مفاتيح API ← إلغاء المفتاح الذي اسمه يبدأ بـ MCP ·. تُرفض الطلبات اللاحقة بهذا المفتاح. إلغاء الوصول لا يتراجع عن عمليات سبق تنفيذها ولا يحذف بيانات قرأها العميل.

إذا لم يكتمل الربط

إذا لم تظهر الشركة، تحقق من عضويتك كمالك أو مدير. إذا انتهت صلاحية الموافقة، ابدأ Connect مجددًا. عند رفض مفتاح منتهي أو ملغى، أعد المصادقة. يمكن للشركة الاحتفاظ بحد أقصى 20 مفتاحًا غير ملغى؛ ألغِ اتصالًا قديمًا عند بلوغ الحد.
